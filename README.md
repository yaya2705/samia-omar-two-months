# Same Sky — Samia × Omar

A tiny interactive anniversary site for 30 August 2026 → 30 September 2026.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder, keeping the `assets` folder in place.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch containing these files and the `/ (root)` folder.
6. Save. GitHub will provide the Pages URL.

## Customising later

- Add more photos to `assets/`.
- Add new `<figure>` blocks in `index.html`.
- Replace the empty gallery frame with future memories.
- Edit the letter whenever you want.
- The two music buttons open Spotify searches rather than auto-playing copyrighted audio.

## Design notes

The site is intentionally understated: midnight blue, warm light, editorial typography, constellation details, and small interactions rather than lots of hearts or animated clichés.
